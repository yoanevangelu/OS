# OS
A collection of code solutions and implementations for various operating systems concepts, shell scripting, and synchronization problems.

## Repository Structure
*   **`BashScripts/`**: Solutions and automation scripts written for Linux shell scripting environments.
*   **`CPrograms/`**: Core systems programming tasks and problem solutions implemented in C.
*   **`Semaphores/`**: Implementations tackling classic synchronization problems, process coordination, and concurrency models.
