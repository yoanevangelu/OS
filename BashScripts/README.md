# OS BashScripts

Welcome to the **BashScripts** directory! This section of the OS repository contains a collection of Bash shell scripts, organized similarly to the C programs collection. 

## Repository Structure

The scripts are divided into categorized directories to keep tasks and projects organized:

*   **`Scripts1/`**: Contains the initial set of bash scripts and exercises.
*   **`Scripts2/`**: Contains the second set of scripts.

## How to Run the Scripts

To execute any of the Bash scripts on a Linux or macOS system, you will need to grant them execution permissions first. 

```bash
./script_name
```
